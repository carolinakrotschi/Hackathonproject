# Factories

The 26 procedural factory buildings (`proc-factory-*`) from the Industrial Agents Hackathon 2026 Track 01 kit,
copied here so the demo app (`app/`) runs without the kit. Only `building.json` is included; the format is
described in section 3 of the kit README.

Licence: CC0 1.0. Generated for the Munich hackathon (source `procedural` in the kit's `ATTRIBUTION.md`).
The kit's other sources (Swiss Dwellings, ResPlan, OpenStreetMap) are not included here.
